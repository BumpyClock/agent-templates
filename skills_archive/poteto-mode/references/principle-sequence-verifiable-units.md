# Sequence work into verifiable units

Group changes by contracts and dependencies.
A coherent unit can include coordinated edits across several files before a meaningful check can pass.

Order units so earlier results resolve uncertainty or provide prerequisites for later work.
Follow repository requirements for independently acceptable commits and pull requests.
Keep deliberate red-test demonstrations local unless the repository permits failed checks in published commits.

Use [verification before completion](../../../programming/references/verification-before-completion.md) for check scope and evidence reuse.
