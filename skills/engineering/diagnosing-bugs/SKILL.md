# Diagnose defects

Read the [systematic diagnosis guide](../../programming/systematic-debugging/guide.md) for the canonical workflow.

When available, read `CONTEXT.md` and relevant ADRs to understand module responsibilities and prior decisions.

Redact secrets before you show commands, outputs, or captured artifacts. Use environment variables for credentials. Quote only relevant evidence from captures that can contain authorization headers or personal data.

When redaction removes necessary evidence, identify the missing detail and request a safe substitute.
