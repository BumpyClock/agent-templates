Compared all existing matching skill trees against upstream main at the revision above.

quizzes. Course workspace paths were already explicitly anchored locally.

Retained local differences from current upstream

  handles cheap fact-finding directly, and does not treat agreement as editing
  permission. Keeps the local programming-quality checklist and description.
- teach: defaults to one-off conversational teaching; persistent course work is
  conditional and has its own reference. Keeps bounded sourcing, observed learning
  evidence, and comparable answer presentation instead of equal character counts.
  Local description remains; invocation flag and argument hint match upstream.
- writing-for-agents: concise decision-oriented checklist with conditional
  references, explicit scope/authorization rules, observable outcomes, and
  acceptance criteria for shared defaults rather than a full upstream essay.
  Local description remains.

No current upstream counterpart was found for autonomous or canvas. These were
left unchanged. No additional skills were imported. Local agents/openai.yaml
metadata and local-only references were preserved.
