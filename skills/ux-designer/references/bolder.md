# Bolder

Use this optional recipe for an expressive new design or stronger emphasis in an existing interface.
When the direction is uncertain, follow the [direction choice rule](../SKILL.md#defaults-not-dogma).
Use [Typeset](typeset.md) as the typography baseline.

## Establish the Scope

For an existing interface, preserve its visual system and the limits of the requested change.
When the brief says "Everything else stays", change only the named target.
If a refinement needs a new system primitive, confirm that scope with the user.
For a new design, choose a coherent visual system from the product, content, and project conventions.
Preserve supplied meaning, readability, accessibility, and required behavior.

## Find the Source of Weak Emphasis

For an existing interface, compare the target with successful elements in the same system.
Inspect how type, proportion, placement, density, and motifs establish their emphasis.
For a new design, identify the content or action that deserves prominence.

## Optional Treatments

Select treatments that address an observed problem or support the chosen direction.

- **System expression:** If the system has a useful motif, amplify it within the target.
- **New identity:** For a new system, choose a motif that expresses the content or task.
- **Hierarchy:** If emphasis is weak, strengthen the primary element through proportion, placement, density, or type.
- **Support:** If nearby elements compete, reduce their emphasis within the requested scope.
- **Rhythm:** If a section needs prominence, try a deliberate change in density or spatial rhythm.
- **Evidence:** If real evidence can lead, give it more visual prominence than decorative support.
- **Effects:** When an effect supports identity, hierarchy, or feedback, consider it.

If necessary evidence is absent, request it rather than invent it.
Use [Data and Evidence](data-and-evidence.md) for claims, placeholders, and mock data.

## Optional Structure Check

For a layout-led treatment, compare the structure with and without text detail.
Check whether emphasis, groups, and progression remain clear.
Keep copy-led designs when the words carry the intended meaning.
Use imagery that serves an identified purpose in the content.

## Verify the Selected Treatments

Inspect the affected output through [Critique](critique.md).
Check whether the result makes the intended emphasis clearer within the chosen visual system.
Check affected readability, controls, and required behavior.
For a scoped refinement, confirm that everything outside the target remains unchanged.
When the selected treatments meet that purpose and no material defects remain within scope, stop.
