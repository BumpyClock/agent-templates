# Quieter

Use this optional recipe for a restrained new design or less visual intensity in an existing interface.
When the direction is uncertain, follow the [direction choice rule](../SKILL.md#defaults-not-dogma).
Use [Typeset](typeset.md) as the typography baseline.

## Choose the Emphasis

Identify the primary task and the emphasis it needs.
For an existing interface, identify which elements compete with that emphasis.
For a new design, choose a restrained direction from the brief, content, and project conventions.

- **Persuasion and experience:** A restrained palette, open space, or lighter typography can support the product's character.
- **Operation and text:** Fewer background accents, flatter surfaces, or less motion can keep attention on the task.

Preserve project conventions, supplied meaning, readability, accessibility, and required behavior.
For a scoped refinement, preserve everything outside the requested target.

## Optional Treatments

Select treatments that address an observed problem or support the chosen direction.

### Color

- If saturation creates unwanted emphasis, compare a less saturated version.
- If accent colors compete, reserve them for fewer roles.
- When it suits the brand, compare pure, warm, and cool neutrals.
- On colored surfaces, compare neutral text with a darker related hue.
- If transparency helps, check the result against each background.
- Preserve contrast that identifies text, controls, and states.

### Visual Weight and Space

- If secondary text competes with primary content, try a lighter role, such as 700 → 500.
- If scale dominates the content, compare smaller type within the typography baseline.
- If groups compete, increase separation without extra distance between frequent actions.
- If a border is decorative, try a thinner or lower-contrast version.
- Preserve necessary control and state boundaries.

### Surfaces and Effects

- If a shape dominates its content, compare a simpler outline or less pronounced radius.
- If surfaces compete, compare flatter surfaces or fewer shadow layers.
- If an effect adds no useful identity or hierarchy, simplify or remove it.
- Retain depth that communicates a state or relationship.

### Motion

- If travel overwhelms feedback, try a shorter distance, such as 10–20px instead of 40px.
- If overshoot distracts, compare a restrained curve such as `ease-out-quart` with the existing motion.
- When spring motion supports clear, restrained feedback, retain it.
- If an animation serves no useful purpose, compare immediate feedback.
- Preserve feedback, continuity, and reduced-motion behavior.

### Composition

- If adjacent elements compete, reduce their scale contrast while the primary element remains distinct.
- If irregular alignment adds noise, compare a common grid or baseline.
- If extreme gaps interrupt the task, compare a more consistent spatial rhythm.
- Retain differences that communicate hierarchy and content relationships.

## Verify the Selected Treatments

Inspect the affected output through [Critique](critique.md).
Check whether the result supports the chosen direction without loss of character, hierarchy, readability, or required behavior.
Apply [Accessibility](accessibility.md) to affected contrast, controls, and motion.
When the selected treatments meet that purpose and no material defects remain within scope, stop.
