Refresh choices

- create-verification-skill and its three examples already matched the pin.
  The refresh replaces Cursor-specific output paths with the active harness's
  project-local skill path and removes the archived maintenance command.
  Startup repairs require authorization. Disposable fixtures cannot bypass
  the behavior under verification. Example data stays in the project.
  The real user path, observable side effects, read-only doctor, dry-run
  boundary checks, owned-process cleanup, and retained proof remain intact.
- how keeps direct, read-only answers and optional complex investigation.
  The explorer and explainer briefs adopt upstream prose simplifications
  without fixed tool names. No prescribed model, agent count, handoff,
  explanation artifact, prototype, commit, or pull request is required.
  Local critique guidance remains available behind its existing conditions.
- show-me-your-work retains the TSV format, evidence checks, and executable
  log helper. The template and helper already match the pinned upstream.
  Local safeguards retain formula neutralization, append-only corrections,
  authorized commits, supplied transcript paths, and conditional review.
  Upstream cross-model review mandates and Cursor transcript assumptions
  remain excluded. Editorial deletions do not remove local safety rationale.
- technical-writing adds concise PR summaries with links to detailed evidence.
  Requested formats may retain inline tables. Repository prose rules,
  accurate uncertainty, existing code format, and conditional document
  structure still govern. No forced document split, tab indentation, or
  unsolicited edits to another skill return.
- unslop adds upstream mannered-prose and over-compression diagnostics with
  examples. Local rules 17 and 18 correspond to upstream rules 32 and 33.
  Rule IDs remain stable locally rather than renumber to match upstream.
  Existing invocation metadata, voice guidance, and shared AGENTS.md ownership
  remain intact. Previously centralized rules are not duplicated here.
  Literal code, CLI syntax, diagrams, and status labels remain unchanged.
